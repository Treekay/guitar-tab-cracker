# Preserved historical evidence

Numbered folders and benchmark-summary files are earlier visual transcription
evidence, retained for future review/V3. They are not V1 crop/order instructions.
The historical nine-image numbering differs from the current ten-image set:
old 1-5 match current 1-5; old 6-9 match current 7-10. Current 6 is the added
middle screenshot. Historical files are preserved without rewriting their data.

legacy-detection-* records the retired application's geometry/review. Historical
paths/statuses are archival, not current acceptance criteria. Fresh V1 decisions
come from opening the current images in ../input/.
